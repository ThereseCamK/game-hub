# GAME HUB
Game Hub is an online game store where visitors can explore games, view information about selected titles, and find options to add games to a shopping cart.

Visitors can also learn more about Game Hub, see information about the employees, and find contact details on a separate contact page.

This project was created using only HTML and CSS as part of my Front-End Development studies at Noroff.

## Live Site

[View Live Site](https://theresecamk.github.io/game-hub/)
[View Code on GitHub](https://github.com/ThereseCamK/game-hub)

## About the project

Game Hub is designed to appeal to young people who enjoy gaming.

The goal was to create a website where visitors can easily discover games and explore new releases.

The colors were chosen to make the website visually interesting, engaging, and fun for a younger audience.

Since the project was built without JavaScript, not all games are clickable or have individual information pages. The website therefore works more as a prototype for a potentially larger project in the future.

## Features

### Homepage

A welcoming hero section.

A carousel showcasing new game releases.

### Games Page

Game thumbnails and cards displaying the available games.

Options to add games to the shopping cart.

The ability to select a game and view more information about that specific title.

### About Page

Information about Game Hub as a company.

Employee cards with names and contact email addresses.

### Contact Page

Contact information, including address and phone number.

Links to social media platforms.

### Cart

SInce it is not used Javascript it is only the visual, not actual working and not checking form.

You can see whats in your cart 

change quantity
 
continue to checkout, where you must fill in shipping, payment and confirm purchase.
